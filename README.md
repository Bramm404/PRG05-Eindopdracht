# The Games Corner

The Games Corner is een webapplicatie voor gamers. Gebruikers
kunnen games ontdekken, zoeken op naam, ontwikkelaar of genre, meerdere genres
filteren en de nieuwste toevoegingen bekijken.

Ingelogde gebruikers kunnen games aan hun favorieten toevoegen, reacties plaatsen
en hun profiel beheren met een profielfoto. Gebruikers die voldoende reacties
hebben geplaatst kunnen zelf games delen met een beschrijving, genres en afbeelding.
Admins kunnen games en reacties beheren.

De applicatie gebruikt Laravel, Blade, Eloquent, Alpine.js en Tailwind CSS. De
authenticatie, validatie, autorisatie, CSRF-bescherming en uploads worden door
Laravel ondersteund. Tests worden uitgevoerd met Pest en frontend-assets worden
gebouwd met Vite.
